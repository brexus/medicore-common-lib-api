# 📦 MediCore Common Lib - API

This repository is the foundational shared library for the entire MediCore ecosystem. It contains the common building blocks-such as Data Transfer Objects (DTOs), enumerations, and global validators - that ensure strict data consistency across the platform. As MediCore scales into a distributed architecture, this library acts as the **single source of truth** for API contracts. It is designed to be imported as a core dependency across all current and future microservices:

## 🚀 Core Features

* **DTOs** 
* **Enums**
* **Validations**

## 🛠️ Local Setup (Installation)

### 📥 1. Clone the repository
```bash
git clone https://github.com/brexus/medicore-common-lib-api
cd medicore-common-lib-api
```

### 🧩 2. Build and Install
```bash
mvn clean install
```
